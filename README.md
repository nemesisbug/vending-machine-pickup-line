One line, one minute: a pickup line a vending machine would use on a
passing human. The machine speaks in its own world — its coil, its
buttons, its exact change — and lands the joke on the last few words.

> Hey, gorgeous — my coil has been holding your favorite hostage all day.
> Press B7 and I'll drop everything for you. Exact change, no strings
> attached.

Why it works: the machine does the talking, not a stranger in a bar. The
coil, the button, the exact change are all the machine's own world, and
the punch — "no strings attached" — is a coil joke that lands on the last
words, warm instead of creepy.

## Run

```sh
python3 main.py
```

Writes the line to `/output/entry.txt` (override with `OUTPUT_DIR`).
